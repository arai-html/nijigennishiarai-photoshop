CHAPTER 01
グラデーションとは？Photoshopで使う3つの方法

グラデーションとは2色以上の色がなめらかに変化する表現です。Photoshopでは大きく3つの方法で使えます。それぞれ用途が異なるので最初に整理しましょう。

① グラデーションツール（G）

ツールバーから「グラデーションツール」を選択してキャンバスをドラッグ。直接レイヤーに描画する最も基本的な方法。バナーの背景やテクスチャ作りに最もよく使う。

背景作成 テクスチャ グラデーション合成
② グラデーション調整レイヤー

レイヤー → 新規塗りつぶしレイヤー → グラデーション から追加。後から何度でも編集できるのが最大の特徴。Lesson02〜05のバナーで使ってきた方法。

後から編集OK 非破壊編集 最推奨
③ レイヤースタイル → グラデーションオーバーレイ

テキスト・シェイプ・画像レイヤーにダブルクリックで適用。そのレイヤーにだけグラデーションを上乗せする方法。テキストのグラデーション・ボタンのグラデーションなどに使う。

テキストに適用 シェイプに適用

どれを使うべき？
バナー背景 → ②調整レイヤー（後から変更できる）
テキストに色 → ③レイヤースタイル
マスクに描く → ①グラデーションツール

カラーストップの操作方法
追加

グラデーションバーの下側をクリックするとカラーストップが追加される。3色以上のグラデーションに使う。

透明グラデーション — 色→透明のフェード

透明グラデーションは色から透明に変化するグラデーションです。写真の境界をなじませたり、テキスト背景を自然に消したりするのに欠かせません。

透明グラデーションの作り方（2種類）
方法①：グラデーションエディターで透明ストップを追加
1. グラデーションエディターを開く
2. バーの上側をクリック → 不透明度ストップを追加
3. 「不透明度」を 0% に設定 → そのストップが透明になる
4. もう一方のストップは 100% のまま
→ 色から透明へのフェードが完成
方法②：プリセット「描画色から透明に」を使う
グラデーションエディターを開く → プリセット一覧の
「描画色から透明に」を選択
→ 現在の描画色から透明になるグラデーションが即座に設定される
一番手軽な方法。描画色を事前に設定しておくこと。

レイヤーマスクへの応用：マスクを選択してグラデーションツールで黒→白のグラデーションを描くと、写真の端が自然に消えます。これはLesson03〜05の写真なじませ技法の仕組みです。

CHAPTER 07
描画モードとグラデーションの組み合わせ

グラデーションレイヤーに描画モードを適用すると、下のレイヤーとの合成方法が変わります。これを使いこなすと表現の幅が劇的に広がります。

乗算（Multiply）
下のレイヤーと掛け合わせて暗くなる。写真に色をのせるとき定番。
スクリーン（Screen）
明るくなる。ネオン・グロー・光のエフェクトに使う。
オーバーレイ（Overlay）
明るい部分はより明るく、暗い部分はより暗く。ノイズレイヤーで使った方法。
ソフトライト（Soft Light）
オーバーレイより柔らかい。写真に色調を加えるときに自然な仕上がりになる。

使い分けの基本：
写真を暗くしたい → 乗算
光・グロー効果 → スクリーン
コントラストを強調 → オーバーレイ
自然な色味追加 → ソフトライト

バナー制作で使える実践テクニック集

Lesson02〜09で実際に使ったグラデーションテクニックを体系的にまとめます。実践で「あのテクニックどうやるんだっけ？」と思ったときの参考にしてください。

テクニック① グラデーション＋ノイズ背景（Lesson01〜02）
★★★ 最頻出
1. 調整レイヤーでグラデーション背景を作る
2. 新規レイヤー → 50%グレーで塗りつぶし
3. フィルター → ノイズ → ノイズを加える（量：8〜25%）
4. 描画モード：オーバーレイ
テクニック② 写真の端を背景になじませる（Lesson03〜05）
★★★ 必須
1. 写真レイヤーのマスクをクリックして選択
2. グラデーションツール（G）で黒→透明を選択
3. なじませたい方向にドラッグ（例：左端をなじませるなら右→左）
4. 必要に応じて複数回ドラッグして調整
テクニック③ 写真をグラデーションで暗くする（Lesson04）
★★ よく使う
1. 写真の上に調整レイヤー → グラデーション を追加
2. ダークカラー → 透明 のグラデーション（例：#1a3a5c → 透明）
3. 描画モード：乗算　不透明度：60〜80%
→ テキストが乗る部分だけ暗くなり文字が読みやすくなる
テクニック④ テキストにグラデーションをかける

2. グラデーションオーバーレイにチェック
3. グラデーションをカスタマイズ・角度を設定
→ テキストにグラデーションが適用される
