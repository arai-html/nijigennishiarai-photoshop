WORK 01 — 基礎
文字ツールの基本操作をマスターする
⏱ 10分
📋 課題
新規ドキュメント（800×800px）を作り、下記の4つのテキストを入力してください。
① ポイントテキスト（1行）
キャンバスをクリック → 「PHOTOSHOP」と入力 → Cmd/Ctrl + Enter で確定
ポイントテキストはクリックで始まる。改行は自動でされない。
② エリアテキスト（複数行）
キャンバスをドラッグしてテキストボックスを描く → 長い文章を入力
エリアテキストはテキストボックス内で自動改行される。ブログ本文・キャプションに最適。
③ 縦書きテキスト
文字ツールを長押し → 縦書き文字ツールを選択 → 「フォトショップ」と入力
日本語の縦書きは自動で縦になる。英字は 文字 → 縦中横 で調整。
④ テキストの変形（ワープ）
テキストレイヤー選択 → オプションバーの「ワープテキストを作成」アイコン → スタイル：円弧 → 適用
バナーのアーチ状テキストなどに使う。
⌨️ 必須ショートカット
T
文字ツールを選択
Cmd/Ctrl + Enter
テキスト入力を確定
Esc
入力をキャンセル
Cmd/Ctrl + A
テキストを全選択
V → T
移動ツール→文字ツール切替
ダブルクリック
テキスト編集モードへ
✅ できたらチェック
ポイントテキストとエリアテキストの違いが分かった
Cmd/Ctrl+Enterで確定できた
縦書き文字ツールを使えた
ワープテキストを試せた

WORK 02 — カーニング
2文字間の隙間を調整する
⏱ 10分
📋 課題
「WAVE」と入力し、W と A の間のカーニングを調整して自然に見えるようにしてください。
カーニングとは？
調整なし
WAVE
❌ WAの間が広い
カーニング後
WAVE
✅ 均等に見える

↑ 「W」と「A」は形の都合上、間が広く見えやすい。カーニングで詰める。

🖱 カーニングの操作方法（2種類）
方法① ショートカットキー（推奨）
カーソルを2文字の間に置く
Option/Alt + ← → 詰める
Option/Alt + → → 広げる
1回 = 20単位ずつ変化
方法② 文字パネルで数値入力
ウィンドウ → 文字パネルを開く
「V/A」のアイコン横の数値を変更
-50〜-100 が詰める目安
文字パネルの読み方
VA ← カーニング
2文字の間に
カーソルを置いて調整
AV ← トラッキング
選択した文字全体の
間隔を一括調整
↕ ← 行送り
行と行の間隔
（複数行テキスト）
T↑ ← ベースライン
文字の上下位置
（上付き・下付き）

カーニングが必要な文字の組み合わせ：
「WA」「AV」「AW」「TA」「VA」「LT」など、斜めの線がある文字の組み合わせは隙間が広く見えやすいです。これらは意識的にカーニングを詰めましょう。

✅ できたらチェック
カーニングとトラッキングの違いが分かった
Option/Alt+矢印でカーニングを調整できた
「WAVE」の文字間が自然に見えるようになった

間延びして迫力ない

✅ 行送り：詰める
Lesson02のイメージ
行送りの設定方法
1

テキストをすべて選択（Cmd/Ctrl + A）

2

文字パネルの ↕（行送り） の値を変更
または Option/Alt + ↑↓

目安の行送り値
フォントサイズ×1.5 → 標準・読みやすい（本文向け）
フォントサイズ×1.0 → ちょうど良い（見出し向け）
フォントサイズ×0.8 → 詰まった迫力（バナー向け）

「自動」と数値の違い：行送りを「自動」にするとフォントサイズの約120%が自動設定されます。バナー制作では数値で指定して自分でコントロールするのが基本です。

✅ できたらチェック

WORK 06 — アウトライン文字
塗りなし・線だけの文字を作る
⏱ 10分
📋 課題
「10%」と大きく入力し、Lesson09で学んだアウトライン文字を再現してください。さらに影ずらしも加えてみましょう。
STEP 1 — テキストを入力
「10%」を入力。フォント：Oswald Bold　サイズ：300px以上
STEP 2 — 文字色を背景と同じにする
文字の色 → 背景色（クリームなら #f5f5e8）に変更
これで文字が「消えて」見える
STEP 3 — 境界線でアウトラインを出す
レイヤースタイル → 境界線
サイズ：5〜8px　カラー：好きな色　位置：外側
STEP 4 — 影ずらしで立体感
レイヤーを Cmd/Ctrl+J で複製 → 下に移動
複製レイヤーの境界線を薄い色（不透明度25%）にして右下に8pxずらす

Lesson09の復習：アウトライン文字は「塗りを背景色と同化させ、境界線だけ見せる」技法です。今回は自分の好きな色でアウトラインを設定してみましょう。

✅ できたらチェック
アウトライン文字を作れた
影ずらしで立体感を出せた
