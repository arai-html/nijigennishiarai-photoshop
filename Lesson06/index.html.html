2色バナーの強さ：色を絞ることで統一感と洗練さが生まれます。ピンク×ブラウンは「かわいさ」と「高級感」を同時に表現できる組み合わせ。今回は素材探しが不要なので、フォント選びと余白に集中しましょう。

「コンデンスド（Condensed）」とは：文字の横幅が通常より細く縦長に設計されたフォントです。大きなサイズでも横にはみ出しにくいため、インパクトを出しながらたくさんの文字を入れられるのが特徴。ファッション系バナーで特によく使われます。

テキストの整列：A〜Dすべて左揃えにします。左端を揃えることで縦の視線の流れが生まれ、読みやすくなります。段落パネル → 左揃え または Cmd/Ctrl + Shift + L で設定。

6
ブラウンのCTA帯を作る（パーツE）

バナー最下段の「詳細はこちら ›」の帯を作ります。長方形シェイプ＋テキスト＋矢印の組み合わせです。

E
CTA帯「詳細はこちら ›」
長方形ツールで横幅いっぱいの帯を描く
高さ：約90〜100px　塗り：#3d1f00（ダークブラウン）

テキスト「詳細はこちら」：游ゴシック Bold 36px #ffffff
トラッキング：+100〜+150（ゆったり間隔で高級感）
矢印「›」：同フォント 40px #ffffff　右端に配置

テキストを帯の中央（上下・左右）に整列
CTA帯の作り方
1

長方形ツール（U） でキャンバス下端に合わせて横幅いっぱいの長方形を描く
塗り：#3d1f00

2

「詳細はこちら」テキストを入力 → 帯の中央（垂直・水平）に整列
整列パネルで「水平中央」「垂直中央」を選択（基準：レイヤー）

3

「›」を別テキストレイヤーで作成 → 帯の右端から30pxの位置に配置

トラッキングを広くとる理由：「詳細はこちら」のトラッキングを +100〜+150 と広めにすると、ファッション系らしいラグジュアリーな雰囲気が出ます。狭いと急いでいる印象になります。

7
全体を整えて仕上げる

全パーツが揃ったら、余白・整列・サイズバランスを最終確認します。

最終チェックリスト
✓

「WINTER SALE」が圧倒的に大きく見えるか

✓

A→B→C→Dの順に文字サイズが段階的に小さくなっているか

✓

左端の余白が均等（ガイドライン：表示 → ガイド を使うと便利）

✓

CTA帯がキャンバスの最下端にピッタリ揃っているか

✓

使っている色がピンク（#f06292）とブラウン（#3d1f00）の2色だけか

📏 ガイドラインで余白を揃える方法
1. 表示 → 新規ガイド を選択
2. 方向：垂直方向　位置：50px → OK
3. 青いガイドラインが表示される
4. テキストの左端をこのラインに揃える
5. 完成後は 表示 → ガイドを消去 で非表示に

Lesson 04・05との最大の違い：今回は素材（写真）が一切不要です。フォント・サイズ・色・余白だけでここまでのインパクトが出せることを体感してください。テキストのみのバナーは作業時間が短く、修正も簡単です。

8
PNG書き出して完成

ファイル → 書き出し → スクリーン用に書き出し... を開き、PNG 形式で保存。サイズが 988 × 990 px になっていることを確認してください。
