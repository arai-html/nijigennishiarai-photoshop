背景写真＋グラデーションオーバーレイで暗くする
1

ビル写真を配置 → Cmd/Ctrl+T で600×600pxに合わせる

2

新規塗りつぶしレイヤー → グラデーション を写真の上に追加

3

グラデーション：#1a3a5c（70%）→ 透明　描画モード：乗算　不透明度：80%

背景を暗くする理由：白いテキストや帯を上に乗せるため、背景が明るすぎると読みにくくなります。グラデーションオーバーレイで左側を特に暗くすると文字エリアが際立ちます。

3
人物写真を配置して切り抜く（パーツD）

人物を右側に配置します。Lesson 02・03と同じ「被写体を選択 → レイヤーマスク」の手順です。

人物写真を埋め込みを配置 で追加 → 右半分に配置

人物レイヤーをグラデーションオーバーレイレイヤーの下に移動 → ビル写真との合成が自然になる

髪の毛の切り抜き：「選択とマスク」で境界線の調整ブラシ（髪の毛アイコン）を使うと、細かい髪の毛も綺麗に切り抜けます。ぼかし量は 0.5〜1px がおすすめ。

4
メインテキスト帯を作る（パーツB）

「大手企業への転職」のオレンジ背景テキスト帯を作ります。長方形シェイプ＋テキストの組み合わせです。

オレンジ帯の作り方
1

長方形ツール（U） でオレンジの帯を描く
塗り：#e85d04　線：なし

2

横書き文字ツール（T） で「大手企業」「への転職」を入力

3

シェイプとテキストを選択 → Cmd/Ctrl + G でグループ化

B
「大手企業への転職」— フォント設定
フォント：游ゴシック / ヒラギノ角ゴ W8
ウェイト：Ultra Bold / Black（最太め）
「大手企業」サイズ：120px　カラー：#ffffff
「への転職」サイズ：80px　カラー：#ffffff
トラッキング：0〜+20

「大手企業」を大きく「への転職」を小さく：視線は大きい文字から小さい文字へ自然に流れます。強調したいキーワードを大きくすることで伝わりやすいバナーになります。

5
情報バッジを作る（パーツC）

「年収700万円」「福利厚生充実」の白い帯バッジを2つ作ります。長方形シェイプ＋角丸＋テキストの組み合わせです。

情報バッジの作り方
長方形ツール — プロパティ
塗り
線
なし
角丸半径
💡 角丸をつけると柔らかい印象に
C
情報バッジ × 2 — フォント設定
白い角丸長方形（角丸：4px）を2つ縦に並べる
フォント：游ゴシック Bold
サイズ：40px　カラー：#1a3a5c（ネイビー）
テキスト：年収700万円 ／ 福利厚生充実

バッジ間隔は均等に揃える → 整列パネル → 垂直方向に分布

バッジを2つ揃える：両方選択して整列パネルの「左端を揃える」を使うと、左端がピッタリ揃います。手動で動かすより確実です。

6
下の帯を2つ作る（パーツE・F）

下部の2段の帯を作ります。E：オレンジ帯（CTA） と F：白帯（ブランド名） です。

E
オレンジ下帯「3人に2人が年収アップ」
長方形ツール で横幅いっぱいの帯を描く
塗り：グラデーション（#e85d04 → #ff8533）左→右
高さ：約60px

テキスト「3人に2人が 年収アップ」：游ゴシック Bold 36px #ffffff
右端に三角矢印（▶）：白い円シェイプ + 「▶」テキスト
F
白帯「転職エージェントならパソナキャリア」
長方形ツール で横幅いっぱいの白い帯
高さ：約50px　塗り：#ffffff

左側バッジ「転職」：ネイビー長方形 #1a3a5c + 白テキスト 24px
テキスト「エージェントなら パソナキャリア」：游ゴシック Bold 28px #1a1a2e
「パソナキャリア」の部分を太くするため別のテキストレイヤーにするとGOOD
帯の配置 — 整列パネルで正確に揃える
1

移動ツール（V）で帯レイヤーを選択 → オプションバーの整列ボタンで水平中央揃え

2

白帯（F）はキャンバス最下端に揃える → 整列パネルの「下端揃え」を使用。基準を「キャンバス」に設定すること！

3

オレンジ帯（E）は白帯（F）のすぐ上に配置。スナップ機能をONにすると吸い付くように揃う。

スナップの活用：表示 → スナップ をONにすると、レイヤーを動かしたとき他のレイヤーやキャンバス端に吸い付きます。帯の位置揃えが格段に楽になります。

7
ロゴを配置する（パーツA）

右上のPASONAロゴを配置します。今回は模写なので自分でテキストで再現します。

A
PASOANロゴの再現
① 赤い丸シェイプ（#e85d04）を小さく作る（12×12px）
② 「PASONA」テキスト：Arial Bold / 游ゴシック Bold 24px #ffffff
③ シェイプとテキストを横に並べてグループ化
④ 右上に配置 → 整列パネルで右端・上端に揃える（余白20px）

実際の仕事では：クライアントからロゴのPNGやAIファイルをもらって配置します。今回のような模写練習では自分でテキストで再現してみましょう。

8
仕上げ・全体調整

全パーツが揃ったら全体のバランスを確認して仕上げます。

仕上げチェックリスト
✓

テキストが背景に埋もれていないか確認（ドロップシャドウを薄く追加してもOK）

✓

人物の切り抜きが不自然でないか確認（髪の毛・肩のライン）

✓

下の2本の帯が左右にはみ出ていないか確認

✓

イメージ → トリミング で余分な白部分がないか確認

✓

スマートフォンで見て文字が読めるか確認

Lesson 02・03との比較：今回は「複数の帯・シェイプ・人物写真」が組み合わさった複合レイアウトです。グループ化（Cmd+G）をうまく使ってレイヤーを整理するとあとから修正しやすくなります。

9
PNG書き出して完成

ファイル → 書き出し → スクリーン用に書き出し... を開き、PNG 形式で保存。サイズが 600 × 600 px になっていることを確認してください。
