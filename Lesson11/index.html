カーニング — 修正問題
おかしい文字間を見つけて直す
⏱ 10分
🎲 ランダム出題：カーニング
📋 課題
下記の3つのテキストを入力し、カーニングがおかしい箇所を修正してください。それぞれどこを・どのくらい調整したか記録しましょう。
問題①「TOKYO」
TOKYO
→ TOの間が広く見える。
カーニングを調整して均等に見せる。
記録欄
調整した箇所：T と O の間　　値：_____ 単位
問題②「WAVE」
WAVE
→ WA・AVどちらの間が問題？
両方チェックして自然に見せる。
記録欄
調整した箇所：_____ と _____　　値：_____ 単位
問題③「STYLE」
STYLE
→ TY・YLの間が詰まって見える。
少し広げてバランスをとる。
記録欄
調整した箇所：_____ と _____　　値：_____ 単位

カーニングの鉄則：「光学的に均等に見える」ことが目標です。数値が均等でなくてもOK。目で見て均等に感じるかどうかで判断しましょう。Option/Alt + ← で詰める、Option/Alt + → で広げる。

✅ できたらチェック
3つすべてのカーニングを調整できた
調整した箇所と値を記録できた
目で見て「均等に見える」状態にできた

整列 — 操作問題
5つのテキストを正確に揃える
⏱ 10分
🎲 ランダム出題：整列
📋 課題
下記の5つのテキストレイヤーを配置して、整列パネルだけを使ってすべて揃えてください。手動で動かすのはNGです。
配置する5つのテキスト
①
「SALE」（200px・太字）→ キャンバス水平中央・上から100px
②
「50% OFF」（80px）→ キャンバス水平中央
③
「2026.1.1〜1.31」（32px）→ キャンバス水平中央
④
「左のバッジ」→ キャンバス左端から40px・垂直中央
⑤
「右のバッジ」→ キャンバス右端から40px・垂直中央

整列の手順：① Cmd+A で全選択 → ② 移動ツール（V）に切替 → ③ 整列パネルで「水平中央」などをクリック。
基準を「キャンバス」に設定しないと正しく揃わないので注意！

✅ できたらチェック

Q8
アウトライン — 応用問題
塗りありとアウトラインを組み合わせる
⏱ 12分
🎲 ランダム出題：アウトライン応用
📋 課題
「50」は塗りあり（白）、「%OFF」はアウトラインのみ（白の境界線）という組み合わせを作ってください。
50
%
OFF

↑ 目標。「50」は白塗り、「%OFF」はアウトラインのみ

1

「50」を入力 → 色：#ffffff（白）→ 通常の塗りあり文字

2

「%」「OFF」をそれぞれ別レイヤーで入力 → 色を背景色（#0070f3）と同じに

3

「%」「OFF」にレイヤースタイル → 境界線：3px #ffffff 外側

4

3つを位置調整して完成。グループ化（Cmd+G）でまとめて管理

✅ できたらチェック
塗りありとアウトラインを組み合わせられた
3つのレイヤーをグループ化できた
